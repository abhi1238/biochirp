# Redistribution-Restricted Databases

This file previously listed local databases under `database/` whose terms of
use **prohibit redistribution** of the underlying data files.

After the 2026-05-14 licensing review, the only such database
(see `LICENSING_REMOVAL.md`) has been removed from the BioChirp service stack.
The current public-tier release therefore ships only redistributable databases
and contains no `LICENSE_RESTRICTED` directories.

If a future database with a redistribution restriction is added, list it here
and place a `LICENSE_RESTRICTED` marker in its `database/<db>/` directory.

Last updated: 2026-05-14.
