Hosted (no install)

One line of config. No Python, no Docker, no install on the user's machine. Connects to the public BioChirp endpoint over Server-Sent Events.

In Claude Desktop: Settings → Connectors → Add Custom Connector and paste this URL:

https://biochirp.iiitd.edu.in/mcp/sse

Or paste this entire JSON snippet into your claude_desktop_config.json:

{
  "mcpServers": {
    "biochirp": {
      "type": "sse",
      "url": "https://biochirp.iiitd.edu.in/mcp/sse"
    }
  }
}

claude.ai connectors (streamable HTTP) can instead use https://biochirp.iiitd.edu.in/mcp. After adding, restart Claude Desktop. The 11 BioChirp database tools (drugs_and_targets_ttd, chemicals_genes_diseases_ctd, genetic_variants_pathogenicity_clinvar, …) plus web_search_live appear in the connectors list.

What you get

11 curated databases
TTD, CTD, HCDT, HPO, ClinVar, Reactome, MSigDB, Orphanet, STRING, UniProt, Open Targets
Per-query provenance
Every database call reports (database version, snapshot date) and a CSV download link for the full result set
Filter trace
Every response states which entity/synonym terms were resolved and used as filters
Live web search
web_search_live for questions outside the scope of the curated databases, clearly labelled as non-curated
Claude does the planning
No LLM inside the server — it's pure query execution; Claude decides which DB(s) to call and how to synthesize results
Open everything
MIT-licensed code · Zenodo-deposited artefacts · live web demo
